# ROLL TCG

**Trading Card Game baseado em Jiu-Jitsu Brasileiro.**

ROLL TCG é um projeto de jogo de cartas colecionáveis inspirado no universo do Jiu-Jitsu Brasileiro, transformando técnicas, posições, estratégias e situações de combate em mecânicas de jogo.

## Objetivo

Desenvolver um Trading Card Game que combine estratégia, construção de decks e tomada de decisões, utilizando elementos técnicos e táticos do Jiu-Jitsu como referência.

## Status do projeto

<badge color="info">Em desenvolvimento</badge>

O projeto está em sua fase inicial de estruturação técnica e definição da arquitetura.
